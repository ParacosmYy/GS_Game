# 真实性标准

目标是靠近正版 KOF2002 / KOF2002UM 的手感、节奏、视觉和流程。这里的“靠近”指工程和体验标准，不指复制商业素材。

## 最高原则

- 帧节奏优先于功能数量。
- 打击反馈优先于新增角色。
- 样板角色优先于全角色铺开。
- 逐帧 sprite 管线优先于继续美化骨骼假人。
- 可复现性优先于临时效果。

## 必须逐步对齐的体验

- 60Hz 固定步长。
- 明确 startup / active / recovery。
- hitstop、blockstop、pushback、hitstun、blockstun 分层。
- 轻/重/必杀/超必杀有不同命中重量。
- 高低段、防御、投技、拆投、GC、MAX、取消、juggle、damage scaling 逐步完整。
- 角色站姿、走路、受击、胜利姿势必须体现性格。
- 肖像、动作、台词、色彩必须统一角色气质。

## 参考资料规则

- 可以参考公开帧数据、公开 wiki、开源引擎结构、MUGEN/IKEMEN 工程做法。
- 不得复制受版权保护的 sprite、音频、screenpack、角色实现。
- 若使用社区资源，必须确认许可并记录来源。
- 无法确认许可的内容只作本地研究，不进入运行时和提交产物。

## 当前最大差距

- 角色仍缺正式逐帧 sprite 资产管线。
- 肖像和角色动作仍有自制感。
- 音频仍未达到采样级街机质感。
- 部分系统还没有完整数据化。
- 真实 QF/KOF 体验依赖大量离线资产和严格帧表，不是单靠代码特效能补齐。
