# 操作说明

## P1

| 按键 | 功能 |
| --- | --- |
| W/A/S/D | 跳跃/左/蹲/右 |
| J | A 轻拳 |
| K | B 轻脚 |
| U | C 重拳 |
| I | D 重脚 |
| ; | 投技 |
| L | CD |
| P | 嘲讽 |

## P2

| 按键 | 功能 |
| --- | --- |
| 方向键 | 移动 |
| Numpad1 | A 轻拳 |
| Numpad2 | B 轻脚 |
| Numpad3 | C 重拳 |
| Numpad0 | D 重脚 |
| Numpad. | 投技 |
| Numpad4 | CD |

## 通用

| 按键 | 功能 |

| Enter / J | 确认 |
| R | 重开 |
| T | 选人界面切换 AI |
| F1 | Debug |
| Tab | 简化模式 |
| N | 切换舞台 |
