## 3. +1 规则

每轮最多 +1。

允许 +1 的情况：

- 推进任意 Phase 1 或 Phase 2 维度的玩家可感知改进。
- 完成可验证的视觉/听觉/手感实质提升。
- 完成角色内容包的一个子域（attacks/hitboxes/feedback/moves等）。
- 建立或强化多角色复制管线。
- 新增深层机制并通过手测或自动验证。
- 修复阻碍主线进展的稳定性问题。
- 明确闭合了 KOF 差距矩阵中的一项高优先级差距。

不得 +1 的情况：

- 只是加测试但不改变玩家体验（纯测试覆盖不算 +1）。
- 微调参数（粒子数/alpha/尺寸微调不算实质改变）。
- 只是美化 placeholder。
- 只是搬目录但没有决策门和验证。
- 验证失败。
- 没有手测或自动验证说明。
- 不能说明更像 KOF 在哪里。

## 4. 每轮评分复盘

每轮必须写：

- 本轮提升哪个维度？
- 为什么只加 1 分？
- 更像 KOF 在哪里？
- 仍不像 KOF 在哪里？
- 下一轮最小任务是什么？
- 下一轮要闭合哪一项差距矩阵。

## 5. Tag 对齐规则

- 每 5 个 commit 形成一个阶段，并同步一次 tag 记录。
- tag 记录只用于阶段标记，不直接替代 `+1` 评分。
- tag 的历史记录口径按 `0.01` 递增。
- 每累计 10 个 tag，按 `0.1` 进位。
- 如果 tag 打点失败，不影响后续 commit 节奏，继续推进并在后续节点补打。
