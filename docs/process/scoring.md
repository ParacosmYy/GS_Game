## 3. +1 规则

每轮最多 +1。

允许 +1 的情况：

- 推进任意 Phase 2 维度。
- 完成一个角色的资产/动作/判定/反馈可验证小闭环。
- 建立或强化多角色复制管线。
- 完成 Kyo/Iori 样板闭环的一个验证步骤。
- 修复阻碍 Phase 2 进展的稳定性问题。
- 新增深层机制（MAX/Free Cancel/Guard Cancel/Juggle 等）并通过手测或自动验证。

不得 +1 的情况：

- 只是美化 placeholder。
- 只是新增系统但不服务 Phase 2 主线。
- 只是搬目录但没有决策门和验证。
- 验证失败。
- 没有手测或自动验证说明。
- 不能说明更像 KOF 在哪里。
- 只是改测试但不改变游戏体验（纯测试覆盖不算 +1）。

## 4. 每轮评分复盘

每轮必须写：

- 本轮提升哪个维度？
- 为什么只加 1 分？
- 更像 KOF 在哪里？
- 仍不像 KOF 在哪里？
- 下一轮最小任务是什么？

## 5. Tag 对齐规则

- 每 5 个 commit 形成一个阶段，并同步一次 tag 记录。
- tag 记录只用于阶段标记，不直接替代 `+1` 评分。
- tag 的历史记录口径按 `0.01` 递增。
- 每累计 10 个 tag，按 `0.1` 进位。
- 如果 tag 打点失败，不影响后续 commit 节奏，继续推进并在后续节点补打。
