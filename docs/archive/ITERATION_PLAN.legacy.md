# 拳皇2002风云再起 (KOF 2002 UM) 终极迭代路线图

> **核心原则**：优先打造硬核的对战博弈逻辑（不好玩一切白搭），随后全面接轨正版级别的视觉体验（告别“假人”与塑料感）。

本路线图按照优先级从高到低排列（P0 -> P3），完全基于当前架构和《拳皇2002 UM》原版标准梳理。

---

## 阶段一：对战系统基石重构 (P0 核心优先级)
*当前对战系统仅是基础的“移动与攻击”，缺少真正格斗游戏的博弈闭环。这一阶段不碰画面，全心打磨物理和机制。*

### 1. 多维判定框系统 (Hitbox Upgrade)
- **缺失问题**：统一的AABB框无法做精细的对战（比如下段攻击必须蹲防、跳跃躲避下段）。
- **任务清单**：
  - [ ] 拆分 **Hurtbox (受击框)**：区分上段、中段、下段，并支持无敌状态的关闭。
  - [ ] 拆分 **Hitbox (攻击框)**：仅在 active 帧出现。
  - [ ] 拆分 **Pushbox (推挤框)**：控制两名角色肉体重叠时的排斥力，不允许穿模。
  - [ ] 拆分 **Throwbox (投技判定框)**：判定是否在投技捕捉范围内。

### 2. 投技与近身判定 (Throws & Proximity)
- **缺失问题**：没有投技会导致防守方可以“永远龟缩”，缺少择的压力。
- **任务清单**：
  - [ ] **普通投系统**：近身前后+C/D触发，并实装**拆投（Tech）**的无敌窗口。
  - [ ] **指令投框架**：无起手帧（0帧投）与有起手帧指令投的底层支持。
  - [ ] **近敌判定 (Proximity)**：近身与远身自动切换攻击动作（如近C与远C的区别）。
  - [ ] **牵制防御 (Proximity Guard)**：对方出招但未命中时，拉后方向会自动做出防御动作而不能移动。

### 3. 指令缓存优化 (Input Buffer & Forgiveness)
- **缺失问题**：手感生涩，连段难按，因为没有搓招的输入容错。
- **任务清单**：
  - [ ] **前向指令留存**：记录前 15-20 帧的输入历史。
  - [ ] **逆向边沿/松开判定 (Negative Edge)**：按下按键和松开按键两次都可以作为指令确定的判定。
  - [ ] **长指令粘性**：允许像 `下 后 下 前` 这种输入中有少量杂乱按键也能识别出超必杀。

---

## 阶段二：视觉重塑与角色生命力 (P1 视觉进化优先级)
*解决“目前人物太假了”的问题，从代码绘制（多半是现在的骨骼矩形拼接）迁移至真正的 2D 逐帧动画引擎表现。*

### 4. 精灵图动画引擎 (Sprite Sheet Rendering)
- **缺失问题**：骨骼拼接或纯几何绘制无法复刻原版细腻的肌肉、衣物摆动和打击形变。
- **任务清单**：
  - [ ] 将当前 `skeletalFighter` 绘制逻辑，替换为读取原版像素精灵图（Sprite Sheets）序列帧的解析器。
  - [ ] 建立基于帧数据 (`startup`, `active`, `recovery`) 的雪碧图播放映射机制。
  - [ ] 制作每个角色的待机（Idle）、受击（Hit）等独有动画，反映性格特征（如八神慵懒、Kula灵动）。
  - [ ] 实现角色配色引擎（通过 Canvas ImageData 替换调色板实现 2P/3P 颜色）。

### 5. 极致打击感 (Hit-stop & Screen Shake)
- **缺失问题**：现在的打击感软绵绵，打中就像切豆腐。
- **任务清单**：
  - [ ] **打击顿帧 (Hit-stop)**：重攻击/必杀技命中瞬间，底层 `gameLoop` 需要让双方角色的动画彻底暂停 6-12 帧，配合特效营造“卡肉感”。
  - [ ] **屏幕震动 (Camera Shake)**：命中重击或者受到指令投砸地时，Canvas 轴向位移动画。

### 6. 视觉特效与原版特质 (VFX Parity)
- **缺失问题**：缺乏格斗游戏中关键的视觉反馈，玩家不知道自己处于什么状态。
- **任务清单**：
  - [ ] 原版材质的受击火花、防御火花。
  - [ ] Super Flash 停帧：释放超必杀时，背景变暗，全屏卡顿，角色爆发高光。
  - [ ] 角色体型基准覆盖：禁止纸片人，必须体现出克拉克、张巨汉的厚重，大门的宽大比例。

## 阶段三：深层攻防机制 (P2 系统深度优先级)
*在系统有了灵魂之后，补全《2002 UM》赖以成名的“立回”与“连段”机制。*

### 7. 防御的高阶派生 (Guard Mechanics)
- **任务清单**：
  - [ ] **Guard Crush (防御崩坏)**：引入隐形防御耐久值，打空进入超长破防硬直（配碎玻璃特效）。
  - [ ] **击飞攻击 (CD键)**：站立和空中的吹飞攻击。
  - [ ] **防御取消 (Guard Cancels)**：
    - GC Roll (防滚)：防御期间按 AB 消耗 1 气无敌翻滚。
    - GC CD (气反)：防御期间按 CD 消耗 1 气推开对手。

### 8. MAX模式与资源管理限制
- **任务清单**：
  - [ ] **MAX 状态激活 (BC爆气)**：角色加速，获取防御加成，按时间流逝槽位。
  - [ ] **Free Cancel (自由取消)**：MAX 中允许必杀技互取，消耗大量 MAX 槽。
  - [ ] **MAX2 / HSDM (隐藏超必杀)**：红血 + MAX 模式才能触发，需要特殊全屏特写和致命伤害机制。
  - [ ] **浮空值与伤害缩放 (Juggle & Scaling)**：连击越多伤害百分比越低，空中连击达到上限则无法追打，防无限连。

### 9. 倒地与受身 (Knockdown & Quick Stand)
- **任务清单**：
  - [ ] 被击飞即将落地瞬间按 AB，立刻前滚或后滚向后侧起身。
  - [ ] 为受身增加标准的无敌帧与起身硬直窗口。

---

## 阶段四：比赛流程与仪式感 (P3 完成度)
*让它玩起来像一个完整的商业游戏，而并非代码测试的 Demo。*

### 10. 流程补全 (Flow Control)
- **任务清单**：
  - [ ] **队伍盲选 (Order Select)**：3v3 的精髓，选择首发、次将和守底。
  - [ ] **特殊宿敌开场 (Special Intros)**：如草薙京与八神的特别动画交互。
  - [ ] 胜利结算界面与 Win Quote。
  - [ ] 打出“Perfect”（满血胜利）的特别闪屏与动画。
  - [ ] **嘲讽机制 (Taunts)**：按 Start 削减对手气槽。

---

## 下一步行动建议指南

**按照这个开发顺序推进最稳妥：**
1. **不要再写任何角色的新招式了**，先停下来，把底层的 `Hitbox` 多维度判定和 `Throwbox` 投技底层做完。不然后面改底层，全部招式都要推倒重来。
2. 底层做完后，把**指令缓冲区**优化好，确保自己用键盘玩能顺畅搓出下后下前。
3. 把渲染层的**骨骼绘制全盘端掉，引入 Sprite Sheet 精灵图绘制引擎**。只有这样人物才会具备原版的张力。
4. 做好受击顿帧、相机震动。
5. 再开始大量铺角色和制作连招。
