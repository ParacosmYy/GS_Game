# 拳皇2002 - 风云再起

KOF 2002 风格 2D 格斗游戏 POC，基于 HTML5 Canvas + TypeScript + Vite 构建。

## 版本

当前版本: **v1.0.0** — 基础战斗 + KOF移动机制

## 快速启动

```bash
# 安装依赖
npm install

# 开发模式 (http://localhost:3000)
npx vite --port 3000

# 或直接运行
play.bat
```

## 操作说明

### P1 (WASD + JKL)
| 按键 | 功能 |
|------|------|
| W | 跳跃 |
| A | 左移 / 后方向 |
| S | 蹲下 |
| D | 右移 / 前方向 |
| J | 轻攻击 (P) |
| K | 重攻击 (K) |
| L | 投技 |

### P2 (方向键 + 456)
| 按键 | 功能 |
|------|------|
| ↑ | 跳跃 |
| ← | 左移 / 后方向 |
| ↓ | 蹲下 |
| → | 右移 / 前方向 |
| 4 (小键盘) | 轻攻击 (P) |
| 5 (小键盘) | 重攻击 (K) |
| 6 (小键盘) | 投技 |

### KOF 移动操作
| 操作 | 指令 |
|------|------|
| 跑步 | 双击→ (快速前冲) |
| 后撤跳 | 双击← (向后跳跃) |
| 跑跳 | 跑步中按↑ (更远更快的跳跃) |

### 必杀技
| 技名 | 指令 |
|------|------|
| 波动拳 | ↓↘→ + P (远程飞行道具) |
| 升龙拳 | →↓↘ + P (对空升龙) |

### 系统操作
| 按键 | 功能 |
|------|------|
| R | 重新开始 |
| F1 | 调试信息 |

## 功能清单 (v1.0.0)

### 战斗系统
- 站立轻击 / 重击 (高段攻击)
- 蹲下攻击 (低段攻击)
- 空中攻击 (跳攻)
- 投技 (近距离不可防御, 翻摔)
- 必杀技: 波动拳 (飞行道具), 升龙拳 (对空无敌)
- 防御: 站防 (挡高段), 蹲防 (挡低段)
- 高低段判定: 空中攻击破蹲防, 蹲攻击破站防

### KOF 移动机制
- 跑步 (双击前方向, 持续前冲)
- 后撤跳 (双击后方向, 固定抛物线后退)
- 跑跳 (跑步中跳跃, 更远更快)

### 视觉效果
- 打击火花 (命中粒子)
- 格挡闪光 (防御特效)
- 伤害数字 (浮动显示)
- 连击计数 (X COMBO)
- 屏幕震动 (根据攻击强度)
- 着地灰尘
- 梯度血条 (绿→黄→红)
- 99秒倒计时
- ROUND 1 FIGHT! 过场动画
- KO 胜负判定画面

## 技术架构

```
src/
├── main.ts                    # 入口 (194行)
├── core/
│   ├── types.ts               # 枚举/接口定义
│   ├── constants.ts           # 常量配置
│   ├── camera.ts              # 镜头跟踪
│   └── gameLoop.ts            # 固定时间步长循环
├── entities/
│   ├── fighter.ts             # 角色实体
│   ├── fighterController.ts   # 状态机 + 输入处理
│   └── projectile.ts          # 飞行道具
├── combat/
│   └── combatSystem.ts        # 战斗判定 + HitCallback
├── input/
│   ├── inputManager.ts        # 键盘输入
│   ├── inputResolver.ts       # 方向解析 + 边沿检测
│   └── commandBuffer.ts       # 方向历史 + 必杀技检测
└── rendering/
    ├── renderer.ts            # 渲染器 (舞台/角色/HUD)
    └── vfx.ts                 # VFX粒子 + 屏幕震动
```
