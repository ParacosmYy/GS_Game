# GS_Game

> 游戏项目合集仓库，用于存放个人游戏 Demo、玩法实验、前端交互和小型项目练习。

## 仓库定位

| 项目 | 说明 |
|------|------|
| 类型 | 游戏 / 交互 Demo 合集 |
| 主要内容 | 小游戏、玩法原型、前端交互、资源实验 |
| 推荐用途 | 练习项目、作品展示、交互逻辑验证 |
| 后续建议 | 按游戏名称拆分子目录，并给每个 Demo 增加截图和运行方式 |

## 建议目录结构

```text
GS_Game/
├── demos/                # 每个小游戏一个子目录
├── assets/               # 公共图片、音频、字体资源
├── docs/                 # 玩法说明、设计记录、截图
├── tools/                # 构建或资源处理脚本
└── README.md
```

## 每个 Demo 建议包含

```text
demos/<game-name>/
├── README.md             # 玩法、运行方式、截图
├── src/                  # 源码
├── assets/               # 该 Demo 独立资源
└── public/               # 静态入口或构建产物
```

## README 编写规范

每个游戏子项目建议说明：

- 游戏目标；
- 操作方式；
- 技术栈；
- 运行命令；
- 截图或录屏；
- 当前完成状态；
- 后续计划。
